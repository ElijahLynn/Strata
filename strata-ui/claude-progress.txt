2026-06-27 — 003: Image thumbnails (TDD red→green, verified headlessly)
- card.js now branches: image mime → a thumb container (St.Widget + BinLayout)
  with a placeholder icon; applyThumbnail(fileUri) swaps in a CSS background-image
  (PNG decoded off the shell thread by the CSS loader, never on the main loop).
- shelf.js orchestrates thumbnails LAZILY, per visible card only:
  _updateVisibleThumbs() intersects each image card's allocation box with the
  hadjustment viewport [value, value+page_size] (skips not-yet-allocated boxes) and
  calls _ensureThumb() only for those in view → off-screen cards issue ZERO D-Bus.
  Driven by hadjustment notify::value/upper/page-size + a post-load idle backstop.
- _ensureThumb: session Map (_thumbCache id→path) + disk cache
  (~/.cache/strata/thumbnails/<id>.png) checked before GetThumbnail; _thumbRequested
  Set prevents re-fetch while visible; cleared on reload (cards rebuilt) but cache kept.
  _fetchThumbnail(id) is the daemon seam (GetThumbnailAsync), stubbed in tests.
- onItemDeleted(id): GLib.unlink the cached PNG + drop the card. (009 wires the
  actual ItemDeleted signal to this.)
